# Chathumini Irosha Liyanage — Portfolio

This is a GitHub Pages-ready personal portfolio website.

## Files
- `index.html` — complete responsive portfolio website
- `CV.pdf` — add your final CV PDF here (the Download CV button already points to it)

## Publish with GitHub Pages

1. Create a GitHub account.
2. Create a **public** repository named `YOURUSERNAME.github.io`.
3. Upload `index.html`.
4. Upload your CV and name it exactly `CV.pdf`.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then click **Save**.
8. After deployment, open `https://YOURUSERNAME.github.io/`.

## Before publishing
- Add your final CV PDF as `CV.pdf`.
- Replace/add your GitHub URL when you create your GitHub account.
- If you later add project screenshots, create a `screenshots` folder and update the project cards.

## Privacy note
The portfolio intentionally does not display the full home address from the CV. The phone number, email and LinkedIn are included for professional contact.
